## Зачем это нужно

Zapret отлично справляется с обходом DPI — но живёт в командной строке: `.bat`-файлы, аргументы, службы, папки с десятком файлов. Одна опечатка, и Discord снова не грузится.

**Control** забирает эту рутину на себя. Это нативное приложение для Windows, которое скачивает сборки Zapret, запускает и останавливает защиту, переключает стратегии и показывает, что происходит на самом деле — вместо чёрного окна с логом.

|  |  |
|:--|:--|
| **Понятно с первого экрана**<br>Одно состояние защиты и одна кнопка. Никаких аргументов и конфигов. | **Всё под контролем**<br>Видно, какая версия активна, какая стратегия работает и что именно запущено в системе. |
| **Готово к ежедневному использованию**<br>Трей, автозапуск, уведомления, восстановление после перезагрузки. | **Ничего лишнего**<br>Без рекламы, телеметрии и аккаунтов. Один установщик и локальные данные. |

## ✨ Возможности

### Защита

- **Запуск и остановка в один клик** — `winws.exe` поднимается и гасится без консольных окон.
- **Честный статус** — Control различает свою защиту, службу автозапуска и чужой `winws.exe`, запущенный из другой папки.
- **Автоперезапуск** — если процесс неожиданно упал, Control поднимет его сам.
- **Проверка перед стартом** — права, драйвер WinDivert и файлы стратегии проверяются до запуска, а не после.

### Подбор стратегии

- **Анализ сети** — провайдер и его номер в реестре, задержка, джиттер, потери, доступность TLS у нужных сервисов.
- **Сравнение всех стратегий** — Zapret и ваши пресеты оцениваются по одним правилам, с понятной оценкой и объяснением выбора.
- **Автопрофиль** — готовая конфигурация под конкретный компьютер, а не усреднённый шаблон.

### Версии Zapret

- **Скачивание прямо в приложении** — список релизов Flowseal с описанием изменений, загрузка и установка без браузера.
- **Несколько версий рядом** — переключение между сборками с перезапуском защиты на лету.
- **Открыть папку или удалить** — версия живёт в своей папке, её видно на диске.

### Профили и фильтры

- **Профили** — сохранённые связки «стратегия + фильтры + списки + fakes». Переключение одним нажатием, обмен файлом профиля.
- **Игровой фильтр** — выключен, весь трафик, только TCP или только UDP.
- **IPSet** — реальный список адресов, работа без фильтра или строгий запрет.
- **Пользовательские списки** — свои домены и исключения с проверкой изменений.
- **Fake-пакеты** — отдельные подмены для Discord и игр.

### Система

- **Служба Windows** — Zapret может работать фоном и стартовать вместе с системой.
- **Диагностика** — права, WinDivert, процесс, версия, файлы стратегий, интернет, DNS и доступ к GitHub. С копированием отчёта.
- **Резервные копии** — настройки, профили и списки в одном файле.
- **TG Proxy** — встроенный MTProto-прокси для Telegram, когда Zapret не нужен.

### Интерфейс

- **Светлая и тёмная темы** — с учётом системной настройки, выбор запоминается.
- **Командная палитра** — `Ctrl + K` находит раздел, стратегию, профиль, версию или действие.
- **Живой отклик** — аккуратные анимации и мгновенная обратная связь на каждое действие.
- **Трей и уведомления** — состояние всегда под рукой, даже когда окно закрыто.

## 📦 Установка

**Требования**

| | |
|:--|:--|
| Система | Windows 10 или 11, 64-bit |
| Права | Администратор — нужны драйверу WinDivert |
| Место | ~16 МБ на диске после установки (установщик ~4,5 МБ) плюс папка с версиями Zapret |

**Шаги**

1. Скачайте последний установщик со [страницы релизов](https://github.com/m0rph1num/Control/releases/latest).
2. Запустите его и подтвердите запрос UAC.
3. Откройте Control — мастер первого запуска проверит систему и предложит папку для данных.

Настройки, профили и скачанные версии Zapret лежат отдельно от файлов программы, поэтому установка поверх их не затрагивает.

---

## 🚀 Первый запуск

1. **Мастер настройки** — проверяет права и WinDivert, выбирает папку данных, спрашивает про трей и уведомления.
2. **Версии** — скачайте актуальную сборку Flowseal Zapret. Без неё обход работать не будет.
3. **Защита** — нажмите **«Подобрать стратегию»**: Control проверит сеть и предложит лучший вариант. Или выберите вручную и нажмите **Запустить**.
4. **Проверка** — откройте YouTube или Discord. Если нестабильно, попробуйте другую стратегию из списка.

## 🔄 Обновление

Control проверяет новые версии сам и показывает плашку в сайдбаре.

1. Нажмите на плашку и подтвердите установку.
2. Control закроется, установит новую версию и откроется снова.
3. Настройки, профили и версии Zapret остаются на месте.

Вручную ничего скачивать не нужно — установщик загружается из официальных релизов этого репозитория.

| Что | Где хранится |
|:--|:--|
| Настройки Control | `%APPDATA%\control\` |
| Профили и конфигурация | `%APPDATA%\control\` |
| Версии Zapret | `C:\Control\` или выбранная папка |
| Пользовательские списки | папка активной версии Zapret |
| Служба `zapret` | службы Windows |

## ❓ Частые вопросы

<details>
<summary><b>Control — это Zapret?</b></summary>

Нет. Control — оболочка. Внутри работает оригинальный `winws.exe` из [Flowseal Zapret](https://github.com/Flowseal/zapret-discord-youtube), его код не изменяется.
</details>

<details>
<summary><b>Почему нужны права администратора?</b></summary>

WinDivert — драйвер уровня ядра, он перехватывает пакеты. Без прав администратора он не запустится, а значит не будет и обхода.
</details>

<details>
<summary><b>Защита не запускается — что проверить?</b></summary>

Откройте **Диагностику**: она покажет, чего не хватает. Чаще всего это не установленный WinDivert или отсутствующая сборка Zapret.
</details>

<details>
<summary><b>Что значит «Zapret работает (внешний)»?</b></summary>

Так помечается `winws.exe`, запущенный из папки, которой Control не управляет. Обход при этом работает, но остановить такой процесс Control не может.
</details>

<details>
<summary><b>Это заменяет VPN?</b></summary>

Нет. Обход DPI помогает там, где трафик фильтруется по протоколу — Discord, YouTube, Twitch. Он не скрывает IP-адрес и не обходит блокировки по адресам.
</details>

<details>
<summary><b>Куда уходят мои данные?</b></summary>

Никуда. В приложении нет телеметрии и аналитики. Сеть используется только для загрузки релизов Zapret, проверки доступности сервисов и поиска обновлений.
</details>

## 🛠 Сборка из исходников

```powershell
git clone https://github.com/m0rph1num/Control.git
cd Control
npm --prefix app install
npm run tauri dev
```

Требуется Node.js 22+, Rust (stable, MSVC toolchain) и WebView2. Подробности об архитектуре и решениях — в [`docs/`](docs/).

| Слой | Технологии |
|:--|:--|
| Оболочка | Tauri 2, Rust, Windows API |
| Интерфейс | React 19, TypeScript, Vite, Tailwind CSS 4 |
| Компоненты | Radix UI, Sonner, Geist, Solar Icons |
| Проверки | ESLint, Vitest, Clippy, rustfmt, GitHub Actions |
