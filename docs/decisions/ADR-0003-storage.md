# ADR-0003: Хранение и миграция данных

Статус: принято.

## Решения

1. Пути не меняются: `%APPDATA%\control` — как в 1.0.1 (settings.json, flowseal-config.json,
   zapret-versions\, temp-downloads\). Обновление поверх 1.0.1 не должно ничего терять.
2. Все записи критичных JSON — атомарные (temp + rename + fsync + post-read validation),
   паттерн `.bak` сохраняется и дополняется ротацией до 3 поколений.
3. Read-Modify-Write с защитой от затирания: перед записью перечитываем файл; изменение
   с момента чтения → ошибка `CONFLICT` (см. STORAGE.md).
4. Схемы: serde-структуры с `#[serde(default)]` + сохранение неизвестных ключей
   (flatten-карта) — старые конфиги читаются, новые поля добавляются безопасно.
   Версия схемы пишется в файл при первой записи (`schemaVersion`, опционально).
5. Повреждённые файлы: копия в `corrupt\`, восстановление из `.bak`, дефолты — последними;
   пользователю показывается что произошло.
6. Backup/restore-формат экспорта остаётся совместимым с 1.0.1 (взаимная переносимость).

## Альтернативы

- SQLite/roonmi-база — отвергнуто: нет пользы, усложняет совместимость и бэкап-экспорт.
- Новая папка данных для Tauri-версии — отвергнуто: теряет обновление поверх 1.0.1.
