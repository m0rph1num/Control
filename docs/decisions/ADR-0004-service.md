# ADR-0004: Служба автозапуска и взаимодействие с ней

Статус: принято.

## Контекст

1.0.1 генерирует `autostart_zapret_service.cmd` (создание службы `zapret` с путём к текущей
стратегии, копирование WinDivert.sys, `sc create WinDivert`) и запускает через
`Start-Process -Verb RunAs`. Регистровый ключ хранит выбранную стратегию.

## Решения

- Функциональность сохраняется (обратная совместимость с уже установленной службой важна:
  при обновлении поверх 1.0.1 служба должна продолжать работать; удаляем/обновляем её только
  по явному действию пользователя).
- Создание/удаление службы — только через elevated helper (ADR-0001) с JSON-планом и отчётом.
- Статус службы — `sc query` с кэшем ≤2 c; статус всегда сверяется с фактом при старте.
- Служба и интерактивный запуск winws считаются взаимоисключающими: перед интерактивным стартом
  при активной службе — понятная ошибка/подтверждение остановки службы (улучшение против
  текущей неоднозначности).

## Альтернативы

- windows-service crate для прямого управления из процесса — отвергнуто: всё равно нужны
  админ-права, helper уже решает эту задачу единообразно.
