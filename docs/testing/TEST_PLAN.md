# Тестирование

## Уровни

| Уровень | Инструмент | Что покрывает |
|---|---|---|
| Rust unit | `cargo test --lib` | операции и их отмена, блокировки, атомарная запись, восстановление настроек из `.bak`, парсинг стратегий, кодировки |
| Frontend unit | Vitest | контракт `shared/api`: имена команд и форма аргументов |
| Статические проверки | `tsc --noEmit`, ESLint, `cargo clippy -D warnings`, `cargo fmt --check` | типы, правила проекта, форматирование |
| Сборка | `vite build`, `cargo build` | фронтенд собирается, Rust линкуется |
| Ручная проверка | чек-лист ниже | то, что нельзя проверить автоматически: реальный `winws`, служба, UAC, трей |

E2E-автоматизации нет: сценарии требуют драйвера WinDivert, прав администратора и живой сети,
поэтому они вынесены в ручной чек-лист релиза.

## Команды

```powershell
npm run typecheck
npm run lint
npm run test
npm run build

cargo fmt --check --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml --lib --all-targets -- -D warnings
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

`--lib` у `cargo test` обязателен локально: бинарь `control-elevate` несёт манифест
`requireAdministrator`, и в обычной консоли тест завершается с `OS error 740`.
В CI ограничения нет.

## Что проверяется автоматически

- **Операции** — переходы статусов, отмена, освобождение блокировки ресурса после завершения,
  таймаут и kill процесса.
- **Хранилище** — сериализация настроек, round-trip неизвестных ключей, конкурентные записи,
  восстановление из `.bak` при повреждённом JSON.
- **Процессы** — параллельное чтение вывода, таймаут, отмена.
- **Контракт API** — имена IPC-команд и форма аргументов на фронтенде.

## Ручной чек-лист релиза

1. Установка на чистую Windows 10/11: UAC, ярлык, запуск, иконка в проводнике и в трее.
2. Первый запуск: мастер, проверки системы, выбор папки, загрузка версии Zapret.
3. Защита: запуск, остановка, повторный запуск, статус после перезапуска приложения.
4. Внешний `winws.exe`: определяется, не убивается, управление блокируется.
5. Служба `zapret`: установка, запуск, удаление, поведение после перезагрузки.
6. Версии: скачивание, установка, переключение на лету, удаление, открытие папки.
7. Профили: создание, применение, экспорт и импорт, удаление.
8. Фильтры: игровой режим, IPSet, пользовательские списки, fake-пакеты.
9. Резервная копия: экспорт, импорт, откат при ошибке.
10. Диагностика: все проверки, копирование отчёта.
11. TG Proxy: установка, запуск, смена порта, остановка.
12. Уведомления Windows: текст и иконка тоста, отсутствие дублей при активном окне.
13. Оформление: светлая, тёмная и системная темы, сохранение выбора.
14. Окно: свёрнутое состояние сайдбара, минимальный размер 1100×720, полноэкранный режим.
15. Обновление поверх предыдущей версии: настройки, профили и версии Zapret на месте.

## CI

`.github/workflows/ci.yml` на `windows-latest`:

| Job | Шаги |
|---|---|
| `frontend` | `npm ci`, `typecheck`, `lint`, `test`, `vite build` |
| `rust` | `cargo fmt --check`, `cargo clippy -D warnings`, `cargo test`, `cargo check --lib` |

Полная сборка установщика в CI не выполняется — релиз собирается локально и проверяется
по чек-листу выше.
